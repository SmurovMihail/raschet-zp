# raschet-zp
Простой и надёжный десктопный инструмент для ежемесячного расчёта заработной платы.
Создан для бухгалтеров малых предприятий, индивидуальных предпринимателей и всех,
кто хочет начислять зарплату сотрудникам без глубоких бухгалтерских знаний.

**Главное достоинство**: все данные хранятся локально на вашем компьютере, вы не зависите от интернета и облачных сервисов.

Целевая аудитория проекта:
- Индивидуальные предприниматели с небольшим штатом.
- Малый бизнес, где нет выделенного бухгалтера-расчётчика.
- Бухгалтеры на аутсорсе, ведущие несколько мелких компаний.
- Все, кому нужно быстро подготовить расчётные листки и налоговую отчётность.

Руководство по установке:
1. Скачайте последнюю версию приложения архивом `fulldaTA.rar` из [Releases](https://github.com/SmurovMihail/raschet-zp/releases).
2. Распакуйте архив и запустите `РасчетЗарплаты.exe` (установка не требуется).
