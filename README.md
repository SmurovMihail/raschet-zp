# raschet-zp
Простой и надёжный десктопный инструмент для ежемесячного расчёта заработной платы.
Создан для бухгалтеров малых предприятий, индивидуальных предпринимателей и всех,
кто хочет начислять зарплату сотрудникам без глубоких бухгалтерских знаний.

Руководство по установке:
1. Скачайте полностью паппку приложения.
2. Запустите РасчетЗарплаты.exe (установка не требуется).
